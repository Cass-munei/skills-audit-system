# Skills Audit System (Web + Mobile)

## Overview
A full-stack system developed to capture, manage, and analyse user skills data across web and mobile platforms.

## Features
- Skills data capture and storage
- User-friendly mobile interface
- Data validation and reporting
- Cross-platform accessibility

## Tech Stack
- ASP.NET MVC (Web)
- Flutter (Mobile)
- SQL Server
